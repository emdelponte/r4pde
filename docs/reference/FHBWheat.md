# FHBWheat dataset

Fusarium head blight quadrat assessments in wheat.

## Usage

``` r
FHBWheat
```

## Format

A data frame with:

- field:

  Field identifier

- i:

  Number of diseased plants in the quadrat (used as `i` by
  [`BPL()`](https://emdelponte.github.io/r4pde/reference/BPL.md))

- n:

  Number of plants assessed in the quadrat (used as `n` by
  [`BPL()`](https://emdelponte.github.io/r4pde/reference/BPL.md))

- quadrat:

  Quadrat ID

- season:

  Crop season

## Source

Del Ponte Lab internal data
